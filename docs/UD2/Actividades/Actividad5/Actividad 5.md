# Actividad 5 · Del prototipo a la web

Recupera la actividad 21 de UD1. El objetivo es construir su contenido y navegación con HTML y una primera distribución CSS; el acabado visual y los estados se profundizan en UD3.

## Trabajo

1. Crea principal, detalle y contacto o pantallas equivalentes de tu recorrido. Organiza los archivos y utiliza rutas relativas.
2. Define títulos, regiones y enlaces según su función; comprueba que el contenido tiene sentido sin CSS.
3. Añade un formulario con etiquetas visibles, ayudas cuando sean necesarias y restricciones nativas justificadas. Usa datos ficticios y documenta que no hay envío real si no existe servidor.
4. Aplica caja, flujo, Flexbox y Grid donde resuelvan la distribución. Revisa un ancho estrecho y uno amplio.
5. Comprueba el HTML, el orden del teclado, los enlaces y la lectura. Corrige y registra al menos una incidencia.

## Entrega UD2-v1

HTML, CSS inicial, recursos, mapa actualizado y README con instrucciones de apertura, decisiones, validación y límites. Incluye dos capturas de referencia, pero entrega también el código y el recorrido funcional.

## Comprobación

| Aspecto | Evidencia |
|---|---|
| Estructura | Elementos elegidos por función y encabezados comprensibles |
| Navegación | Enlaces que llegan al destino esperado |
| Formulario | Etiquetas, restricciones justificadas y recorrido Tab |
| Distribución | Contenido legible en ambos anchos |
| Continuidad | Diferencias respecto al prototipo y tareas pendientes para UD3 |

Conserva UD1-v1 y explica los cambios. La actividad no exige un framework ni un servicio de envío real.
