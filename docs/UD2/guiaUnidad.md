# UD2 · HTML y CSS inicial

Partimos de **UD1-v1: contenido, mapa y prototipo**. Al terminar conservarás **UD2-v1: HTML conectado, formulario y CSS inicial**.

Sigue estos bloques en el orden indicado. Las fechas y entregas se comunican en clase. Aplica lo aprendido a tu proyecto y conserva las evidencias con el identificador del bloque.

## B01 · Del contenido a HTML

**Consulta:** [html5](<html5.md>).

**Práctica:** Estructura semántica del proyecto.

Construye principal, detalle y contacto con títulos y enlaces descriptivos.

**Evidencia para avanzar:** Contenido comprensible sin CSS y navegación funcional.

## B02 · Formularios y verificación

**Consulta:** [html5](<html5.md>) · [seoVerificación](<seoVerificación.md>).

**Práctica:** A1: contacto, tabla de datos y validación.

Asocia etiquetas; prueba campos, orden Tab y restricciones nativas con datos ficticios.

**Evidencia para avanzar:** Formulario comprobado y errores de validación corregidos.

## B03 · Caja y flujo

**Consulta:** [conceptosBásicos](<conceptosBásicos.md>).

**Práctica:** A1: primera distribución.

Relaciona margen, padding, ancho y flujo con tu prototipo.

**Evidencia para avanzar:** Explicación de una caja en el inspector.

## B04 · Flexbox y Grid

**Consulta:** [layout](<layout.md>).

**Práctica:** A2–A4.

Resuelve navegación con Flexbox y tarjetas con Grid; compara los cambios al estrechar.

**Evidencia para avanzar:** Prácticas más aplicación propia sin desbordamiento involuntario.

## B05 · Integración

**Consulta:** [Actividad 5](<Actividades/Actividad5/Actividad 5.md>).

**Práctica:** A5 proyecto.

Conecta el recorrido, conserva CSS inicial y registra qué mejorarás en UD3.

**Evidencia para avanzar:** UD2-v1 con README, validación y dos tamaños comprobados.

## Cierre y continuidad

Revisa tu entrega, guarda la versión y registra una decisión, su motivo y qué afecta después. [Ver el hilo del módulo](../mapaModulo.md).
