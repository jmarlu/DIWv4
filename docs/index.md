# Diseño de interfaces web · DIWv4

Aprende a diseñar, construir y revisar una interfaz web. Empezarás con un problema y terminarás con un proyecto que puedas explicar y comprobar.

## Empieza aquí

1. Lee la [guía de UD1](UD1/guiaUnidad.md) y prepara tu proyecto.
2. Utiliza [Mirada](UD1/Ejemplo_Figma_Mirada.md) para practicar las técnicas que se muestran en clase.
3. Aplica lo aprendido a tu propia web. Conserva una versión al terminar cada unidad.

| Etapa | Lo que consigues |
|---|---|
| [UD1 · Diseño](UD1/guiaUnidad.md) | Brief, contenido, sistema visual y prototipo |
| [UD2 · HTML y CSS inicial](UD2/guiaUnidad.md) | Páginas conectadas, formulario y primera distribución |
| [UD3 · CSS](UD3/guiaUnidad.md) | Diseño adaptable, estados y comportamiento visual |
| [UD4 · Organización y Sass](UD4/guiaUnidad.md) | Estilos mantenibles y compilación reproducible |
| [UD5 · Tailwind](UD5/guiaUnidad.md) | Componentes equivalentes y comparación con CSS |
| [Multimedia](Multimedia/guiaUnidad.md) | Recursos preparados e integrados con alternativas |
| [Accesibilidad](Accesibilidad/guiaUnidad.md) | Pruebas, correcciones y comprobación de resultados |
| [Usabilidad](Usabilidad/guiaUnidad.md) | Observación de tareas y mejora del proyecto |

Los bloques finales amplían el recorrido sin cambiar la numeración histórica de UD1–UD5. Consulta el [hilo del módulo](mapaModulo.md) y la [información de evaluación](informacionModulo.md). Las fechas, pesos y condiciones aplicables son los comunicados por el docente de acuerdo con la programación.

## Cómo leer el material

**Recorrido de clase:** sigue la guía de cada unidad en orden. **Consulta:** vuelve a los apuntes cuando necesites recordar una propiedad. **Ampliación e historia:** profundiza o compara técnicas anteriores cuando se indique; no todo el material de consulta constituye una entrega adicional.
