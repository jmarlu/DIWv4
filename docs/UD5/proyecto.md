# Proyecto UD5 · Comparar CSS y Tailwind

Reimplementa la cabecera y la sección de tarjetas de tu proyecto utilizando Tailwind. Conserva la versión CSS.

1. Usa la versión de aula y el archivo de bloqueo. Anota instalación, compilación y ubicación del CSS que enlaza el HTML.
2. Traslada colores, fuentes y espaciado del diseño a tokens cuando corresponda.
3. Implementa estados y adaptación sin perder etiquetas, navegación ni foco visible.
4. Prueba contenido largo y los mismos anchos/tareas en ambas versiones.
5. Compara repetición, legibilidad del código y facilidad de cambiar un valor común. Justifica ventajas y límites observados.

**Entrega UD5-v1:** ambas implementaciones o referencias a sus versiones, comandos reproducibles y comparación. No se exige otra landing completa. Los ejemplos avanzados de la teoría quedan disponibles para ampliación.

En `lab`, desarrollo y producción generan `css/output.css`, enlazado desde su HTML. La salida histórica `outputBuild.css`, si existe, se conserva como recurso anterior y no es el punto de entrada de DIWv4.
