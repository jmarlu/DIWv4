# Proyecto UD4 · Mantener sin romper

El objetivo es reorganizar UD3-v1 y conservar su comportamiento.

- Describe dónde se repetían valores o reglas y qué estructura adoptas.
- Usa módulos Sass y un punto de entrada. Mantén HTML y CSS generado localizables.
- Fija dependencias y documenta instalación y compilación.
- Comprueba principal, detalle y formulario en dos anchos, incluyendo foco y estados.
- Guarda UD4-v1 y compara con UD3-v1. Distingue refactorización de rediseño.

**Para terminar:** otra persona puede compilar con tus instrucciones y localizar el archivo que debe modificar para cambiar una tarjeta. La cantidad de carpetas no es un criterio de calidad.
