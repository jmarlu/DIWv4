# Actividad 2 · Estados, adaptación y contenido variable

Construye una tarjeta, una acción y un campo de formulario del proyecto. Esta actividad cubre la práctica que estaba sin enunciado en la versión anterior.

## Pasos

1. Define los valores de color, espacio y tipografía mediante propiedades personalizadas CSS.
2. Implementa una tarjeta con título, descripción, disponibilidad y enlace. Repite con un título largo.
3. Implementa una acción con estado normal, hover y foco visible. Usa enlace para navegar y botón para una acción.
4. Añade un campo con `label`, ayuda vinculada y un ejemplo de error textual. Si simulas el error, decláralo; CSS no valida por sí solo un formulario.
5. Utiliza Grid o Flexbox y una consulta de medios cuando la composición lo necesite. Comprueba 390 y 1280 px como referencias y un tamaño intermedio.
6. Recorre la interfaz con Tab, amplía el texto y revisa desbordamientos. Si hay movimiento, comprueba la variante con preferencia de movimiento reducido.

## Entrega

HTML, CSS y README con pruebas, resultado y correcciones. Incluye una tabla con estado, selector y función de cada regla relevante.

**Para avanzar:** el texto largo no se recorta involuntariamente, el foco se ve, la etiqueta permanece al escribir y el error no depende solo del color. Aplica estos mismos componentes al proyecto de UD3.

Los recursos de animación de esta carpeta se mantienen para experimentar después de resolver los estados esenciales.
