# Proyecto UD3 · Aplicar el sistema visual

Parte de UD2-v1 y de la guía visual de UD1. Trabaja sobre el mismo contenido y recorrido.

1. Traduce paleta, tipografía y espaciado a reglas compartidas.
2. Aplica distribución adaptable; usa contenido real y títulos largos.
3. Implementa normal, foco, disponibilidad y error según las necesidades del proyecto.
4. Ajusta imágenes sin deformación y añade movimiento solo cuando tenga una función explicable.
5. Comprueba teclado, anchos estrecho/intermedio/amplio, texto ampliado y preferencia de movimiento reducido cuando corresponda.
6. Registra una incidencia de cascada con selector, regla ganadora y solución.

Entrega `UD3-v1` con código, recursos e informe breve de pruebas. Conserva el diseño anterior y anota los cambios. UD4 reorganizará estos estilos: no debe empezar con otra web.
