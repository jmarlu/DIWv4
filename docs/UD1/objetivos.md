# UD1 · Diseñar antes de implementar

En esta unidad aprenderás a justificar la estructura y el aspecto de una interfaz. El resultado será un diseño que puedas utilizar al construir tu web con HTML y CSS inicial en UD2 y profundizar en su sistema visual en UD3.

No necesitas programar para completar la unidad. Necesitas manejar archivos, preparar contenido y explicar qué tarea debe poder realizar una persona.

## Qué debes saber hacer al terminar

- Identificar usuarios, contexto y tareas sin confundir hipótesis con observaciones.
- Organizar contenido y representar un recorrido de navegación.
- Utilizar jerarquía, proximidad y contraste para comunicar.
- Elegir y documentar color, tipografía, espaciado e iconos.
- Crear componentes e instancias y comprobar contenido variable.
- Presentar un prototipo y justificar decisiones a partir de una revisión.

## La entrega que continúa en UD2

La [actividad 21](Actividades.md#actividad-21) reúne brief, mapa, guía visual, componentes, prototipo y revisión. La página principal se diseña en un ancho estrecho y otro amplio. El recorrido de una tarea puede representarse mediante bocetos de las pantallas necesarias: no se exige desarrollar toda la web en Figma.

Conserva una exportación local junto al enlace al prototipo y un registro de decisiones. En UD2 usarás estos materiales para organizar documentos HTML y navegación; la guía visual se implementará progresivamente con CSS.

## Accesibilidad desde el diseño

El diseño debe mostrar etiquetas comprensibles, contraste de texto, acciones distinguibles y errores explicados con texto. Representa los estados de foco como especificaciones para la implementación. Dibujar un foco en Figma no demuestra que el teclado funcione en la web final.

En esta unidad se reconoce la función y procedencia de imágenes e iconos. El tratamiento de audio/vídeo, los detalles de compilación y la auditoría técnica completa se reservan para sus bloques.
